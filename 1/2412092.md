## 4. Prompt nguyên văn và trao đổi với công cụ

### TP-01 – Prompt chuẩn

```text
Design a prototype for a health tracking application with a Vietnamese interface, encompassing two modules: a smartwatch interface (smartwatch screen size) and a smartphone interface (smartphone screen size). The user wears the watch during workouts; the watch records activities, and the smartphone app displays and analyzes the results. The prototype should include screens that represent the following functionalities.

Smartwatch Module:
- **Activity Tracking:** The watch automatically detects activity type (walking, running, cycling, swimming) and displays it. Show real-time data including distance, duration, average speed, and current heart rate. Include a command to end the activity.
- **End and Sync:** Upon ending, the watch stops tracking and confirms activity recording. Temporarily store activity data on the watch and automatically sync to the smartphone via Bluetooth when paired. Display sync status (pairing pending, syncing, synced).

Smartphone Module:
- **Activity List:** Chronological list of activities, each entry showing activity name, type (walking, running, cycling, swimming), date, time, and distance. Display total activities and distance above the list, with options to filter statistics by week, month, or year.
- **Activity Details:** Accessed from the activity list. Display route on a map; show total time, distance, calories burned, and elevation change. Toggle views for speed or heart rate statistics, including average values for the entire route, per kilometer, and time-based graphs. Include a button to share results on social media.
- **Schedule and Goals:** Create recurring activity schedules, specifying activity name, type (walking, running, cycling, swimming, other), frequency (daily or selected days), enable/disable reminders, and set minutes before reminders. Set goals by distance, time, or average speed.

Use sample data, not real personal data.
```

### TP-02 - Sửa thêm lượng calo và độ cao thay đổi theo quảng đường và thời gian

```text
Update the existing health tracking prototype to clearly display calories burned and elevation changes during each workout in the smartphone module. Keep the interface in Vietnamese and maintain the existing visual style, screens, and functionality.

On the smartphone Activity Details screen, implement the following:

1. \*\*Calories burned\*\*
- Display a prominent summary card labeled “Calo tiêu thụ”, with the value in kcal.
- Add a chart showing cumulative calories burned over the course of the workout.
- Allow users to tap or drag across the chart to see the elapsed time and calories burned at that point.

2. \*\*Elevation changes\*\*
- Add an elevation profile chart labeled “Độ cao”, showing elevation in meters throughout the workout.
- Let users switch the horizontal axis between elapsed time and distance.
- Display total elevation gain (“Tổng độ cao tăng”), total elevation loss (“Tổng độ cao giảm”), and minimum and maximum elevation.
- Allow users to tap or drag across the chart to inspect the elevation at a specific point.

Place these features alongside the existing route map, duration, distance, speed, and heart rate statistics. Use clearly labeled tabs or sections to keep the smartphone layout readable.

Use realistic, internally consistent sample workout data. Make the chart controls and navigation interactive. Implement these updates directly in the prototype.
```
### TP-03 - Sửa thêm tính năng hiển thị tốc độ và nhịp tim trung bình theo buổi tập

```text
Update the existing smartphone Activity Details screen to display average speed and average heart rate for each workout.

- Add a summary card labeled “Tốc độ trung bình”, displaying the average speed in km/h.
- Add a summary card labeled “Nhịp tim trung bình”, displaying the average heart rate in bpm.
- In the speed and heart rate statistics views, display the corresponding workout average above the chart and as a labeled horizontal reference line.
- Include average speed and average heart rate for each kilometer in the per-kilometer breakdown.

Keep all interface text in Vietnamese and maintain the existing visual style and functionality, including calories burned and elevation changes. Use realistic sample data consistent with the workout’s distance, duration, and charts.

Implement these updates directly in the existing prototype.
```

### TP-04 - Sửa thêm tính năng hiển thị tốc độ và nhịp tim trung bình theo từng km

```text
Update the existing smartphone Activity Details screen to add a per-kilometer breakdown of average speed and average heart rate.

Add a section labeled “Thống kê từng km” with the following columns:
- “Đoạn”: Km 1, Km 2, Km 3, and so on.
- “Tốc độ trung bình”: average speed for that kilometer, in km/h.
- “Nhịp tim trung bình”: average heart rate recorded within that kilometer, in bpm.

Calculate each row using data from that specific segment. Do not repeat the overall workout averages across all rows. If the workout ends with an incomplete kilometer, include a final row showing its actual distance, such as “4–4,5 km”.

Keep the overall workout average cards visible and clearly distinguish them from the per-kilometer statistics. Use realistic sample data consistent with the workout’s total distance, duration, and existing charts.

Keep all interface text in Vietnamese, follow the existing visual style, and implement this feature directly in the current prototype.
Implement these updates directly in the existing prototype.
```

### TP-05 - Biểu đồ hiển theo từng mốc thời gián

```text
Before making changes, check whether the existing smartphone Activity Details screen already includes charts showing speed and heart rate over time.

If these charts already exist and meet the requirements, reuse them without creating duplicate charts, tabs, or sections. If they only partially meet the requirements, update the existing components to add the missing functionality. Create a new chart section only if none exists.

The charts should include:
- Tabs labeled “Tốc độ” and “Nhịp tim”.
- Elapsed workout time on the horizontal axis.
- Speed in km/h or heart rate in bpm on the vertical axis.
- Interactive inspection of the time and corresponding value by tapping or dragging.
- A labeled reference line showing the overall workout average.

Keep all interface text in Vietnamese. Preserve the existing visual style and other features, and use sample data consistent with the workout summary and per-kilometer statistics. Implement the necessary updates directly in the current prototype.
```

### TP-06 - Chỉnh sửa chia sẽ lên mạng xã hội

```text
Update the existing smartphone module to support customizable sharing of workout results to social media, including Facebook, Instagram, and other platforms.

First, check the existing sharing feature. Reuse and extend it where available; avoid creating duplicate buttons, screens, or components.

\*\*Sharing scope\*\*
Allow users to share:
- A single workout from its Activity Details screen.
- A weekly, monthly, or yearly summary from the Activity List or statistics screen.
- Let users select the specific week, month, or year.

\*\*Content selection\*\*
Before sharing, open a customization screen labeled “Tùy chỉnh nội dung chia sẻ”. Provide individual checkboxes or toggles so users can include or exclude each available item:
- Activity name and type.
- Date, time, or summary period.
- Number of workouts.
- Distance and duration.
- Calories burned.
- Average speed and average heart rate.
- Elevation statistics.
- Route map.
- Speed, heart rate, and elevation charts.
- Per-kilometer statistics.

Show only items relevant to the selected sharing scope. Calculate period summaries from workouts within the selected period. Calculate average speed using total distance divided by total duration, rather than averaging workout averages.

\*\*Preview and sharing\*\*
- Display a live preview that updates as users select or deselect content.
- Excluded content must not appear in the shared image, caption, or other shared output.
- Provide layouts suitable for a square post and a vertical Story.
- Let users choose Facebook, Instagram, or “Ứng dụng khác”, and provide an option labeled “Lưu ảnh”.
- Allow users to review the final content before initiating sharing.
- Disable sharing when no content is selected and show a clear Vietnamese explanation.

For this prototype, use sample data and simulate platform sharing with a clearly labeled confirmation. Do not claim that content has actually been posted. Make content selection, period selection, layout switching, and the preview interactive.

Keep all interface text in Vietnamese, maintain the existing visual style, and preserve other functionality. Implement these updates directly in the current prototype.
```

### TP-07 - Chỉnh sửa bố cục thân thiện

```text
Reorganize the existing smartphone interface into separate tabs instead of placing all features on one long scrolling page. Implement the changes directly in the current prototype.

Use a persistent bottom navigation bar with four main tabs:
- “Hoạt động”: activity history and access to individual workout details.
- “Thống kê”: weekly, monthly, and yearly summaries, with sharing for the selected period.
- “Lịch tập”: recurring schedules and reminder settings.
- “Mục tiêu”: create, view, and track distance, duration, or average-speed goals.

Within each Activity Details screen, use secondary tabs:
- “Tổng quan”: route map and summary cards for duration, distance, calories, average speed, average heart rate, and elevation.
- “Biểu đồ”: speed, heart rate, calories, and elevation charts, with a metric selector showing one chart at a time.
- “Từng km”: average speed and average heart rate for each kilometer, including any final partial kilometer.

Keep a clearly visible “Chia sẻ” action on Activity Details. Open sharing customization and preview in a dedicated screen or modal.

Navigation requirements:
- Display only the selected tab’s content.
- Allow scrolling within a tab when necessary, but do not stack all tabs’ contents vertically.
- Clearly highlight the active tab.
- Preserve selected filters, chart settings, and scroll position when switching tabs.
- Keep navigation and back actions consistent.
- Keep period filters within “Thống kê”; retain useful date filters in “Hoạt động” without duplicating the full statistics dashboard.
- Reuse and reorganize existing components instead of creating duplicate features.

Apply this tab structure to the smartphone module. Keep the smartwatch interface focused on workout tracking and synchronization.

Preserve all existing functionality and sample data, maintain the current visual style, and keep all user-facing text in Vietnamese. Verify that every tab, selector, and navigation action works.
```

### CS-2 – Thêm phần xem lịch để người dùng dễ theo dõi

```text
Enhance the existing “Lịch tập” tab by adding today’s schedule and a monthly calendar. This is an additive update: preserve all existing schedule sections, controls, data, and functionality. Do not remove, replace, or hide existing features.

**Add today’s schedule**
- Add a section labeled “Lịch tập hôm nay”, showing today’s date.
```
